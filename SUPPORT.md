# Support

Official project contact: **@mikakhadm**

Before asking for support, include:

- DARK NOC version
- Hub or Node operating-system version
- The action which failed
- Redacted output of the relevant service status and journal

Never send panel passwords, Agent enrollment tokens, SSH keys, database files
or unredacted production addresses. Security vulnerabilities belong in a
private GitHub Security Advisory, not a public issue or chat.
